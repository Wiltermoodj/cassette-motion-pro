Cassette Motion Pro v0.11.2 - Metric Review Package Summary

This update adds a Bike Metrics review summary text file to report packages and
zipped packages.

What changed:

- Adds Bike Metrics Review.txt to report package folders.
- Zipped packages also include Bike Metrics Review.txt.
- The file includes ready/needs-review status, missing values, values to
  double-check, next action guidance, and advisory reminders.
- The file is generated during Package and Zip even if Review Metrics was not
  clicked first.
- Keeps the v0.11.1 detailed Review Metrics button.
- Keeps the v0.10.9 handoff notes workflow.
- Keeps the v0.10.8 Zip workflow.
- Keeps the v0.10.7 report package folder workflow.
- Keeps the v0.10.6 report preview workflow.
- Keeps the v0.10.5 Fit Summary workflow.
- Keeps the v0.10.4 installer resource hardening.
- Updates app/build/installer/report versions to 0.11.2.

Upload steps:

1. Open your GitHub repository:
   https://github.com/spooled/cassette-motion-pro

2. Upload everything from this package to the repo root.

   Important:
   - Include the hidden .github folder.
   - The workflow file must end up here:

     .github/workflows/build.yml

3. Commit with this message:

   Add v0.11.2 metric review package summary

4. Go to Actions.

5. Open the newest run.

6. Download:

   CassetteMotionPro-Windows-0.11.2

What to test:

1. Open Bike Fit Workspace.
2. Open or create a fit session.
3. Open the Bike Metrics tab.
4. Leave at least one key Bike Metric blank.
5. Click Package.
6. Confirm the package contains Bike Metrics Review.txt.
7. Open Bike Metrics Review.txt.
8. Confirm it lists missing/double-check items and advisory reminders.
9. Click Zip.
10. Confirm the zip also contains Bike Metrics Review.txt.
11. Open INSTALLER-BUILD-STATUS.txt from the Windows bundle.
12. Confirm it says Installer build status: SUCCESS.
13. Confirm the bundle contains CassetteMotionPro-Installer-0.11.2.exe.
14. Run the installer on Windows.
15. Confirm the app opens after install.
