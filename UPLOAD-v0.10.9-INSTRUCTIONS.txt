Cassette Motion Pro v0.10.9 - Client Handoff Notes

This update adds handoff notes for client follow-up and includes them in report
packages and zipped packages.

What changed:

- Adds a Handoff tab to the Bike Fit Workspace.
- Handoff fields include what to send, client message, homework/rides, next
  appointment, and internal notes.
- Report package folders include Client Handoff Notes.txt.
- Zipped packages also include Client Handoff Notes.txt.
- Keeps the v0.10.8 Zip workflow.
- Keeps the v0.10.7 report package folder workflow.
- Keeps the v0.10.6 report preview workflow.
- Keeps the v0.10.5 Fit Summary workflow.
- Keeps the v0.10.4 installer resource hardening.
- Updates app/build/installer/report versions to 0.10.9.

Upload steps:

1. Open your GitHub repository:
   https://github.com/spooled/cassette-motion-pro

2. Upload everything from this package to the repo root.

   Important:
   - Include the hidden .github folder.
   - The workflow file must end up here:

     .github/workflows/build.yml

3. Commit with this message:

   Add v0.10.9 client handoff notes

4. Go to Actions.

5. Open the newest run.

6. Download:

   CassetteMotionPro-Windows-0.10.9

What to test:

1. Open Bike Fit Workspace.
2. Open or create a fit session.
3. Open the Handoff tab.
4. Fill in a few handoff fields.
5. Click Package.
6. Confirm the package folder contains Client Handoff Notes.txt.
7. Open Client Handoff Notes.txt.
8. Confirm your handoff notes are included.
9. Click Zip.
10. Confirm the zip contains Client Handoff Notes.txt.
11. Open INSTALLER-BUILD-STATUS.txt from the Windows bundle.
12. Confirm it says Installer build status: SUCCESS.
13. Confirm the bundle contains CassetteMotionPro-Installer-0.10.9.exe.
14. Run the installer on Windows.
15. Confirm the app opens after install.
