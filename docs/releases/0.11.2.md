# Cassette Motion Pro v0.11.2

## Metric review package summary

This release adds a saved Bike Metrics review summary to every report package
and zipped package.

### Changes

- Adds `Bike Metrics Review.txt` to report package folders.
- Zipped packages include `Bike Metrics Review.txt` automatically.
- The review text includes:
  - Ready / needs-review status
  - Missing key values
  - Values to double-check
  - Next action guidance
  - Advisory reminder
  - Saddle setback sign reminder
- The review file is generated during `Package` and `Zip`, even if the
  `Review Metrics` button was not clicked first.
- Updates build, installer, app, portable, and report versions to `0.11.2`.

### Test checklist

1. Upload this package to GitHub.
2. Wait for Actions to finish.
3. Download `CassetteMotionPro-Windows-0.11.2`.
4. Confirm `INSTALLER-BUILD-STATUS.txt` says `SUCCESS`.
5. Confirm `CassetteMotionPro-Installer-0.11.2.exe` is present.
6. Install or run the app on Windows.
7. Open a client and a fit session.
8. Leave at least one key Bike Metric blank.
9. Click `Package`.
10. Confirm the package contains `Bike Metrics Review.txt`.
11. Open the text file and confirm it lists missing/double-check items.
12. Click `Zip`.
13. Confirm the zip also contains `Bike Metrics Review.txt`.
