# Cassette Motion Pro v0.11.4

Session summary package update.

## What changed

- Adds `Session Summary.txt` to generated report package folders.
- Zipped report packages also include `Session Summary.txt`.
- The summary includes client, bike, session/date/status, report view, fit
  summary fields, key bike metrics, body angles, recommendations/notes, and a
  handoff reminder when handoff notes are filled in.
- `README - Open This First.txt` now points to `Session Summary.txt` as the
  quick plain-text overview file.
- Keeps the v0.11.3 clean handoff package workflow.
- Keeps the v0.11.2 `Bike Metrics Review.txt` package workflow.
- Updates build, installer, app, portable, and report versions to `0.11.4`.

## Test checklist

1. Build with GitHub Actions.
2. Download `CassetteMotionPro-Windows-0.11.4`.
3. Confirm `CassetteMotionPro-Portable-0.11.4.zip` is present.
4. Confirm `CassetteMotionPro-Installer-0.11.4.exe` is present.
5. Open the app on Windows.
6. Open Bike Fit Workspace.
7. Open or create a fit session with some fit summary, bike metrics, and notes.
8. Click `Package`.
9. Confirm the package contains `Session Summary.txt`.
10. Confirm the package still contains `README - Open This First.txt`,
    `Bike Fit Report.html`, `Bike Metrics Review.txt`,
    `Client Handoff Notes.txt`, and `Images`.
11. Open `Session Summary.txt` and confirm the contents are useful.
12. Click `Zip`.
13. Confirm the zip contains the same package files.
