# Cassette Motion Pro v0.10.7

## Client report package

This release adds a one-click report package folder for easier client handoff
and review.

### Changes

- Adds a `Report Package` button to the Bike Fit Workspace.
- The button saves the session, generates a package report, and opens the
  finished package folder.
- Creates a folder in the client `Reports` folder named for the fit date,
  client, and session.
- Includes `Bike Fit Report.html` inside the package.
- Copies selected report images into an `Images` folder and points the packaged
  report at those copied images.
- Updates build, installer, app, portable, and report versions to `0.10.7`.
- Keeps v0.10.6 report preview, v0.10.5 Fit Summary, and v0.10.4 installer
  hardening.

### Test checklist

1. Upload this package to GitHub.
2. Wait for Actions to finish.
3. Download `CassetteMotionPro-Windows-0.10.7`.
4. Confirm `INSTALLER-BUILD-STATUS.txt` says `SUCCESS`.
5. Confirm `CassetteMotionPro-Installer-0.10.7.exe` is present.
6. Install or run the app on Windows.
7. Open a client and a fit session.
8. Add at least one report image.
9. Click `Report Package`.
10. Confirm a package folder opens.
11. Confirm it contains `Bike Fit Report.html`.
12. Confirm it contains an `Images` folder with copied report images.
13. Open the packaged HTML report and confirm images show.
