# Cassette Motion Pro v0.12.1

Report prepared-by polish update.

## What changed

- Generated reports include a `Report prepared by` block in the header.
- Generated reports include `Cassette Fit Studio` / professional bike fitting
  prepared-by wording.
- Generated reports include studio contact placeholder text.
- Generated reports include confidential bike fit report wording.
- Generated reports include a cleaner prepared-by/contact footer for PDFs.
- `Session Summary.txt` includes the prepared-by line for consistency.
- Keeps the v0.12.0 professional report polish workflow.
- Keeps the v0.11.4 `Session Summary.txt` package workflow.
- Keeps the v0.11.3 clean handoff package workflow.
- Updates build, installer, app, portable, and report versions to `0.12.1`.

## Test checklist

1. Build with GitHub Actions.
2. Download `CassetteMotionPro-Windows-0.12.1`.
3. Confirm `CassetteMotionPro-Portable-0.12.1.zip` is present.
4. Confirm `CassetteMotionPro-Installer-0.12.1.exe` is present.
5. Open the app on Windows.
6. Open Bike Fit Workspace.
7. Open or create a fit session with fit summary fields, bike metrics, notes,
   and at least one report image if available.
8. Click `Preview Report` or `Generate Report`.
9. Confirm the report shows `Report prepared by` near the header.
10. Confirm the footer shows prepared-by, studio contact placeholder, and
    confidential report wording.
11. Use `Print / Save PDF` and confirm the print layout still looks good.
12. Click `Package`.
13. Confirm the package still contains `Session Summary.txt`,
    `README - Open This First.txt`, `Bike Metrics Review.txt`,
    `Client Handoff Notes.txt`, `Bike Fit Report.html`, and `Images`.
14. Open `Session Summary.txt` and confirm it includes `Prepared by`.
15. Click `Zip`.
16. Confirm the zip contains the same package files.
