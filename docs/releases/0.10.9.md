# Cassette Motion Pro v0.10.9

## Client handoff notes

This release adds a post-fit handoff workflow so client follow-up information
can travel with the report package without changing the client-facing report.

### Changes

- Adds a `Handoff` tab to the Bike Fit Workspace.
- Adds fields for what to send, client follow-up message, homework/ride
  instructions, next appointment, and internal notes.
- Saves handoff fields with each fit session.
- Adds `Client Handoff Notes.txt` to report package folders.
- Zipped report packages include the handoff notes text file automatically.
- Updates build, installer, app, portable, and report versions to `0.10.9`.
- Keeps v0.10.8 zipped packages, v0.10.7 package folders, v0.10.6 report
  preview, v0.10.5 Fit Summary, and v0.10.4 installer hardening.

### Test checklist

1. Upload this package to GitHub.
2. Wait for Actions to finish.
3. Download `CassetteMotionPro-Windows-0.10.9`.
4. Confirm `INSTALLER-BUILD-STATUS.txt` says `SUCCESS`.
5. Confirm `CassetteMotionPro-Installer-0.10.9.exe` is present.
6. Install or run the app on Windows.
7. Open a client and a fit session.
8. Open the `Handoff` tab and fill in a few fields.
9. Click `Package`.
10. Confirm the package folder contains `Client Handoff Notes.txt`.
11. Open the text file and confirm your handoff notes are included.
12. Click `Zip`.
13. Confirm the zip also contains `Client Handoff Notes.txt`.
