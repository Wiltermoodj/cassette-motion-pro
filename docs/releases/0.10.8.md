# Cassette Motion Pro v0.10.8

## Report package zip

This release adds a one-click zip file for easier report handoff.

### Changes

- Adds a `Zip` button to the Bike Fit Workspace.
- The button saves the session, creates a fresh report package, zips it, and
  opens the client Reports folder.
- The zip includes `Bike Fit Report.html` and copied report images from the
  package `Images` folder.
- Adds .NET Framework zip references required for package creation.
- Updates build, installer, app, portable, and report versions to `0.10.8`.
- Keeps v0.10.7 report packages, v0.10.6 report preview, v0.10.5 Fit Summary,
  and v0.10.4 installer hardening.

### Test checklist

1. Upload this package to GitHub.
2. Wait for Actions to finish.
3. Download `CassetteMotionPro-Windows-0.10.8`.
4. Confirm `INSTALLER-BUILD-STATUS.txt` says `SUCCESS`.
5. Confirm `CassetteMotionPro-Installer-0.10.8.exe` is present.
6. Install or run the app on Windows.
7. Open a client and a fit session.
8. Add at least one report image.
9. Click `Zip`.
10. Confirm the Reports folder opens.
11. Confirm a `.zip` report package was created.
12. Open the zip and confirm it contains `Bike Fit Report.html` and `Images`.
