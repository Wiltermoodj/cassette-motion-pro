# Cassette Motion Pro v0.10.6

## Report preview review

This release makes generated reports easier to review before saving or sending a
client PDF.

### Changes

- Adds a `Preview Report` button to the Bike Fit Workspace.
- Preview Report saves the session, generates the HTML report, and opens it
  immediately.
- Adds a browser-only `Review before sending` checklist at the top of generated
  reports.
- The review checklist is hidden when printing or saving the report as PDF.
- Updates build, installer, app, portable, and report versions to `0.10.6`.
- Keeps the v0.10.5 Fit Summary workflow and v0.10.4 installer hardening.

### Test checklist

1. Upload this package to GitHub.
2. Wait for Actions to finish.
3. Download `CassetteMotionPro-Windows-0.10.6`.
4. Confirm `INSTALLER-BUILD-STATUS.txt` says `SUCCESS`.
5. Confirm `CassetteMotionPro-Installer-0.10.6.exe` is present.
6. Install or run the app on Windows.
7. Open a client and a fit session.
8. Click `Preview Report`.
9. Confirm the report opens in the browser.
10. Confirm the top of the report shows `Review before sending`.
11. Click `Print / Save PDF`.
12. Confirm the review checklist does not appear in the print/PDF preview.
