# Cassette Motion Pro v0.11.0

## Bike metrics review

This release starts a measurement-confidence phase by adding a simple review
step before generating reports.

### Changes

- Adds a `Review Metrics` button to the Bike Metrics tab.
- Checks whether key Bike Metrics fields are missing:
  - Saddle height
  - Saddle setback
  - Saddle tip to grip reach
  - Handlebar X
  - Handlebar Y
- Flags broad unusual final/After values for review.
- Shows `Ready for report` when key metrics are filled and values look within
  broad expected ranges.
- Keeps the checks advisory only; they do not block saving, reporting,
  packaging, or zipping.
- Updates build, installer, app, portable, and report versions to `0.11.0`.
- Keeps v0.10.9 handoff notes, v0.10.8 zipped packages, v0.10.7 package
  folders, v0.10.6 report preview, v0.10.5 Fit Summary, and v0.10.4 installer
  hardening.

### Test checklist

1. Upload this package to GitHub.
2. Wait for Actions to finish.
3. Download `CassetteMotionPro-Windows-0.11.0`.
4. Confirm `INSTALLER-BUILD-STATUS.txt` says `SUCCESS`.
5. Confirm `CassetteMotionPro-Installer-0.11.0.exe` is present.
6. Install or run the app on Windows.
7. Open a client and a fit session.
8. Open the Bike Metrics tab.
9. Click `Review Metrics` with some key values blank.
10. Confirm the app lists missing values.
11. Fill in the key After values.
12. Click `Review Metrics` again and confirm it reports ready or shows only
    values to double-check.
