# Cassette Motion Pro v0.11.1

## Metric review details

This release improves the Bike Metrics review message so it gives better
guidance instead of only saying that something is missing or unusual.

### Changes

- Keeps the `Review Metrics` button from v0.11.0.
- Explains whether Before, After, or both sides are missing.
- Adds next-action guidance for each missing key measurement.
- Explains why out-of-range values are flagged.
- Shows the broad review range directly in the message.
- Adds a saddle setback reminder: behind BB should be negative.
- Reminds users to recheck Guided Capture, calibration, or manual entries when
  values look unusual.
- Updates build, installer, app, portable, and report versions to `0.11.1`.

### Test checklist

1. Upload this package to GitHub.
2. Wait for Actions to finish.
3. Download `CassetteMotionPro-Windows-0.11.1`.
4. Confirm `INSTALLER-BUILD-STATUS.txt` says `SUCCESS`.
5. Confirm `CassetteMotionPro-Installer-0.11.1.exe` is present.
6. Install or run the app on Windows.
7. Open a client and a fit session.
8. Open the Bike Metrics tab.
9. Click `Review Metrics` with key values blank.
10. Confirm the message explains which side is missing and what to do next.
11. Enter an unusual After value, such as saddle setback `200 mm`.
12. Click `Review Metrics` again and confirm it explains the expected range and
    next action.
