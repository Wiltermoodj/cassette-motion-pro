# Cassette Motion Pro v0.12.2

Studio contact settings prep update.

## What changed

- Generated reports show studio contact placeholders as separate lines:
  `Fitter`, `Phone`, `Email`, and `Website`.
- Generated report header contact block is cleaner.
- Generated report footer contact block is cleaner.
- `Session Summary.txt` includes `Prepared by`, `Fitter`, `Phone`, `Email`,
  and `Website` placeholders.
- Keeps the v0.12.1 prepared-by/confidential report wording.
- Keeps the v0.12.0 professional report polish workflow.
- Updates build, installer, app, portable, and report versions to `0.12.2`.

## Test checklist

1. Build with GitHub Actions.
2. Download `CassetteMotionPro-Windows-0.12.2`.
3. Confirm `CassetteMotionPro-Portable-0.12.2.zip` is present.
4. Confirm `CassetteMotionPro-Installer-0.12.2.exe` is present.
5. Open the app on Windows.
6. Open Bike Fit Workspace.
7. Open or create a fit session with fit summary fields and bike metrics.
8. Click `Preview Report` or `Generate Report`.
9. Confirm the report header shows separate Fitter, Phone, Email, and Website
   contact placeholders.
10. Confirm the report footer shows the same contact placeholders.
11. Use `Print / Save PDF` and confirm the print layout still looks good.
12. Click `Package`.
13. Open `Session Summary.txt` and confirm it includes the contact placeholder
    lines.
14. Click `Zip`.
15. Confirm the zip contains the same package files.
