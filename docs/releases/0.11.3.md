# Cassette Motion Pro v0.11.3

Clean handoff package update.

## What changed

- Adds `README - Open This First.txt` to generated report package folders.
- Zipped report packages also include `README - Open This First.txt`.
- The package readme explains which file to open first, when to review bike
  metrics, when to use handoff notes, and why the `Images` folder should stay
  with the report.
- Report package folder names now use clearer separators and Cassette Motion
  Pro labeling.
- Keeps the v0.11.2 `Bike Metrics Review.txt` package workflow.
- Updates build, installer, app, portable, and report versions to `0.11.3`.

## Test checklist

1. Build with GitHub Actions.
2. Download `CassetteMotionPro-Windows-0.11.3`.
3. Confirm `CassetteMotionPro-Portable-0.11.3.zip` is present.
4. Confirm `CassetteMotionPro-Installer-0.11.3.exe` is present.
5. Open the app on Windows.
6. Open Bike Fit Workspace.
7. Open or create a fit session.
8. Click `Package`.
9. Confirm the package contains `README - Open This First.txt`.
10. Confirm the package still contains `Bike Fit Report.html`,
    `Bike Metrics Review.txt`, `Client Handoff Notes.txt`, and `Images`.
11. Open `README - Open This First.txt` and confirm the instructions are clear.
12. Click `Zip`.
13. Confirm the zip contains the same package files.
