# Cassette Motion Pro v0.12.0

Professional report polish update.

## What changed

- Generated reports have a more polished professional cover/header.
- Report sections have cleaner spacing and stronger visual hierarchy.
- Fit Summary panels now stand out more clearly.
- Visual Fit Review, Measurement Reference Image, Bike Measurements, and Body
  Angles sections are grouped into cleaner report cards.
- Bike Metrics and Body Angles tables have improved spacing, striping, and
  card-style borders.
- Print / Save PDF styling is improved.
- Keeps the v0.11.4 `Session Summary.txt` package workflow.
- Keeps the v0.11.3 clean handoff package workflow.
- Keeps the v0.11.2 `Bike Metrics Review.txt` package workflow.
- Updates build, installer, app, portable, and report versions to `0.12.0`.

## Test checklist

1. Build with GitHub Actions.
2. Download `CassetteMotionPro-Windows-0.12.0`.
3. Confirm `CassetteMotionPro-Portable-0.12.0.zip` is present.
4. Confirm `CassetteMotionPro-Installer-0.12.0.exe` is present.
5. Open the app on Windows.
6. Open Bike Fit Workspace.
7. Open or create a fit session with fit summary fields, bike metrics, notes,
   and at least one report image if available.
8. Click `Preview Report` or `Generate Report`.
9. Confirm the report looks more polished and readable.
10. Use `Print / Save PDF` and confirm the print layout still looks good.
11. Click `Package`.
12. Confirm the package still contains `Session Summary.txt`,
    `README - Open This First.txt`, `Bike Metrics Review.txt`,
    `Client Handoff Notes.txt`, `Bike Fit Report.html`, and `Images`.
13. Click `Zip`.
14. Confirm the zip contains the same package files.
