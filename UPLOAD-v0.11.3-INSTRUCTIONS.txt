Cassette Motion Pro v0.11.3 - Clean Handoff Package

This update makes report packages easier to open, review, zip, and hand off.

What changed:

- Adds README - Open This First.txt to report package folders.
- Zipped packages also include README - Open This First.txt.
- The readme tells you to open Bike Fit Report.html first, review Bike Metrics
  Review.txt, use Client Handoff Notes.txt if needed, and keep the Images
  folder with the report.
- Report package folder names now use clearer separators and Cassette Motion
  Pro labeling.
- Keeps the v0.11.2 Bike Metrics Review.txt package workflow.
- Keeps the v0.11.1 detailed Review Metrics button.
- Keeps the v0.10.9 handoff notes workflow.
- Keeps the v0.10.8 Zip workflow.
- Keeps the v0.10.7 report package folder workflow.
- Keeps the v0.10.6 report preview workflow.
- Keeps the v0.10.5 Fit Summary workflow.
- Updates app/build/installer/report versions to 0.11.3.

Upload steps:

1. Open your GitHub repository:
   https://github.com/spooled/cassette-motion-pro

2. Upload everything from this package to the repo root.

   Important:
   - Include the hidden .github folder.
   - The workflow file must end up here:

     .github/workflows/build.yml

3. Commit with this message:

   Add v0.11.3 clean handoff package

4. Go to Actions.

5. Open the newest run.

6. Download:

   CassetteMotionPro-Windows-0.11.3

What to test:

1. Open Bike Fit Workspace.
2. Open or create a fit session.
3. Open the Bike Metrics tab.
4. Leave at least one key Bike Metric blank.
5. Click Package.
6. Confirm the package folder name is easier to read.
7. Confirm the package contains README - Open This First.txt.
8. Open README - Open This First.txt.
9. Confirm it tells you to open Bike Fit Report.html and review Bike Metrics
   Review.txt.
10. Confirm Bike Metrics Review.txt is still included.
11. Click Zip.
12. Confirm the zip also contains README - Open This First.txt and Bike Metrics
    Review.txt.
13. Open INSTALLER-BUILD-STATUS.txt from the Windows bundle.
14. Confirm it says Installer build status: SUCCESS.
15. Confirm the bundle contains CassetteMotionPro-Installer-0.11.3.exe.
16. Run the installer on Windows.
17. Confirm the app opens after install.
