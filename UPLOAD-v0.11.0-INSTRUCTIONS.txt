Cassette Motion Pro v0.11.0 - Bike Metrics Review

This update adds a first-pass Bike Metrics review so missing or unusual values
are easier to catch before reporting.

What changed:

- Adds a Review Metrics button to the Bike Metrics tab.
- Checks missing saddle height, saddle setback, saddle-tip-to-grip reach,
  handlebar X, and handlebar Y.
- Flags broad unusual final/After values that may need another look.
- Checks are advisory only and do not block save, report, package, or zip.
- Keeps the v0.10.9 handoff notes workflow.
- Keeps the v0.10.8 Zip workflow.
- Keeps the v0.10.7 report package folder workflow.
- Keeps the v0.10.6 report preview workflow.
- Keeps the v0.10.5 Fit Summary workflow.
- Keeps the v0.10.4 installer resource hardening.
- Updates app/build/installer/report versions to 0.11.0.

Upload steps:

1. Open your GitHub repository:
   https://github.com/spooled/cassette-motion-pro

2. Upload everything from this package to the repo root.

   Important:
   - Include the hidden .github folder.
   - The workflow file must end up here:

     .github/workflows/build.yml

3. Commit with this message:

   Add v0.11.0 bike metrics review

4. Go to Actions.

5. Open the newest run.

6. Download:

   CassetteMotionPro-Windows-0.11.0

What to test:

1. Open Bike Fit Workspace.
2. Open or create a fit session.
3. Open the Bike Metrics tab.
4. Click Review Metrics while some key values are blank.
5. Confirm it lists missing values.
6. Fill in key After values.
7. Click Review Metrics again.
8. Confirm it says Ready for report or only lists values to double-check.
9. Confirm Generate, Preview, Package, Zip, and Reports still work.
11. Open INSTALLER-BUILD-STATUS.txt from the Windows bundle.
12. Confirm it says Installer build status: SUCCESS.
13. Confirm the bundle contains CassetteMotionPro-Installer-0.11.0.exe.
14. Run the installer on Windows.
15. Confirm the app opens after install.
